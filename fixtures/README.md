# Фикстуры

Манифесты и gradle-файлы из трёх собственных Android-проектов автора.
Источник данных для аудита — только свой код, что полностью укладывается
в правила хакатона (см. [`../DATA_SOURCES.md`](../DATA_SOURCES.md)).

| Фикстура | Источник | Чем интересна |
| --- | --- | --- |
| `ne-prospi` | будильник | 14 разрешений, включая `USE_FULL_SCREEN_INTENT`, `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`, `SCHEDULE_EXACT_ALARM`. Два модуля с разными манифестами |
| `mesh-network` | p2p-мессенджер | `BLUETOOTH_SCAN`/`NEARBY_WIFI_DEVICES` рядом с `ACCESS_FINE_LOCATION`, `foregroundServiceType=connectedDevice` |
| `project` | Flutter-приложение | Расщепление манифестов `main`/`debug`/`debugOptimized` — тест на слияние манифестов и утечку debug-настроек в релиз |

## Что сюда намеренно не попало

- **Gradle-файлы `project`.** В исходном репозитории папка `android/`
  целиком в `.gitignore`, а в `build.gradle` блок `debug` содержит пароль
  подписи литералом (стандартный отладочный keystore Android). В публичный
  репозиторий сабмишена это не едет.
- **Любой keystore.** См. правила в корневом `.gitignore`.

## Что сюда намеренно не записано

Список нарушений. Фикстуры скопированы механически, без анализа — чтобы
ручной замер baseline в фазе 0 остался честным. Сначала меряешь себя,
потом строишь инструмент.
