# bob_sessions — ОБЯЗАТЕЛЬНЫЙ ДЕЛИВЕРАБЛ

Здесь лежат скриншоты **task session consumption summary** из Bob IDE.
Без этой папки проект **не допускается к судейству**.

## Как снять скриншот

1. В Bob IDE открой панель чата → **Tasks**.
2. Выбери задачу, относящуюся к сабмишену. Убедись, что ты в нужном
   workspace (если задачи из разных — нажми **All**).
3. Кликни по **заголовку задачи** — откроется session consumption summary.
4. Сделай скриншот этой панели (`Win+Shift+S`).
5. Сохрани через хелпер (см. ниже) — он сам положит файл сюда с правильным именем.

Повтори для **каждой** задачи, связанной с проектом.

## Формат имени

```
<team>_task<NN>_<short_description>_summary.png
```

Пример из гайда: `teamalpha_task01_login_flow_summary.png`

- только PNG (чётче текст);
- номер задачи с ведущим нулём: `task01`, а не `task1`;
- описание в snake_case, без пробелов и кириллицы.

## Хелпер

После `Win+Shift+S` (картинка в буфере обмена):

```bash
powershell -File tools/new-session-shot.ps1 -Task 1 -Desc login_flow
```
