# Источники данных

Правила хакатона требуют вести список сайтов, откуда взяты данные, и отвечать
за их совместимость с коммерческим использованием.

## Разрешено

- Публичные веб-данные, **если условия сайта разрешают коммерческое использование**
- Собственные/синтетические данные
- Открытые датасеты с явной лицензией (MIT, CC0, CC-BY, Apache-2.0 и т.п.)

## Запрещено

- Данные клиентов
- Конфиденциальные данные компании
- Персональные данные (PI)
- Данные из социальных сетей
